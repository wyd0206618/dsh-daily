# 云端方案（不用你的电脑）

> 解决：电脑不会一天开 10 小时，出门在外也想拿到最新数据。

---

## 原理

`cloud_now.py` 不读任何本地文件，全部走公开 HTTP 接口：

| 内容 | 接口 | 需要 Key |
|---|---|---|
| 价格 + 20 日历史 | 新浪期货日K / 外汇日K | 不需要 |
| 实时价 | 新浪 hq.sinajs.cn | 不需要 |
| 今日美国数据 | akshare 百度日历（失败则从新闻抽） | 不需要 |
| 快讯 | 见闻 awtmt 域名 | 不需要 |
| 发邮件 | QQ 邮箱 SMTP | **需要授权码** |

所以它可以跑在任何一台联网的机器上，包括 GitHub 的免费云端。

## 方案 A：GitHub Actions（免费，推荐）

### 一次性配置（约 15 分钟）

**1. 建仓库**

```
打开 https://github.com/new
仓库名随意，比如 dsh-daily
Private 或 Public 都行（Private 每月 2000 分钟免费，够用）
```

**2. 上传三个文件**

在仓库页面点 `Add file → Upload files`，上传：

```
cloud/cloud_now.py
.github/workflows/now.yml
（可选）cloud/README.md
```

**上传时注意保持目录结构**：GitHub 网页上传支持拖文件夹。

**3. 配置邮件密钥**

```
仓库页 → Settings → Secrets and variables → Actions → New repository secret
```

依次添加四个：

| Name | Value |
|---|---|
| `MAIL_USER` | `68239305@qq.com` |
| `MAIL_PASS` | QQ 邮箱的 **SMTP 授权码**（不是登录密码）|
| `MAIL_TO` | `68239305@qq.com` |
| `MAIL_HOST` | `smtp.qq.com` |

**授权码在哪拿**：QQ 邮箱 → 设置 → 账号 → POP3/IMAP/SMTP 服务 → 开启并生成授权码。

**4. 手动测一次**

```
仓库页 → Actions → 左侧 cloud-now → 右侧 Run workflow → Run
```

等 1–2 分钟，看是否收到邮件。日志里会有抓取详情。

**5. 之后自动运行**

已配好三个时间（北京时间）：

```
08:30　早间
21:35　美国数据刚公布（最关键）
22:35　补延迟
```

**注意：GitHub 的定时任务可能延迟 5–30 分钟，不是精确到分钟。**

## 方案 B：任意一台常开的机器

**旧笔记本、树莓派、公司服务器都行。**

```bash
pip install akshare
export MAIL_USER=68239305@qq.com
export MAIL_PASS=你的授权码
export MAIL_TO=68239305@qq.com
python cloud/cloud_now.py --send
```

配 cron：

```cron
30 0 * * *  cd /path && python cloud/cloud_now.py --send
35 13 * * * cd /path && python cloud/cloud_now.py --send
35 14 * * * cd /path && python cloud/cloud_now.py --send
```

## 云端版和本地版的差别

| | 云端版 | 本地版 |
|---|---|---|
| 需要电脑开机 | ❌ 不需要 | ✅ 需要 |
| 六链完整判定 | ❌ 只有 20 日趋势 | ✅ 六条链逐条 |
| Helious 加息概率 | ❌ 无 | ✅ 有 |
| ETF 资金流 | ❌ 无 | ✅ 有 |
| 数据体检 | ❌ 简版 | ✅ 完整 |
| 速度 | 1–2 分钟（含排队）| 6 秒 |

**所以：出门用云端版看方向和事件，回家用本地版看六链细节。**

## 常见问题

**Q：收不到邮件**
```
① Actions 日志里看是否报「缺 MAIL_USER / MAIL_PASS」
② 确认 MAIL_PASS 是授权码，不是 QQ 登录密码
③ QQ 邮箱 → 设置 → 账号 → 确认 SMTP 服务已开启
```

**Q：日历显示「从新闻抽取」**
```
百度会限流（同一 IP 调用过多）。
GitHub 每次是全新 IP，通常不会有这个问题。
本地频繁调用时会遇到，稍等再试。
```

**Q：能改时间吗**
```
改 .github/workflows/now.yml 里的 cron。
格式是 UTC：北京时间 = UTC + 8。
北京 21:35 → UTC 13:35 → "35 13 * * *"
```

**Q：Private 仓库会花钱吗**
```
GitHub Actions 每月免费 2000 分钟。
这个任务每次约 1–2 分钟，一天 3 次 = 每月约 180 分钟。
远在免费额度内。
```
